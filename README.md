## Featured Agent Projects

### 🤖 [RightNow — Agent Workflow Lab](https://github.com/Martin-2712/Rightnow)

A practical playground for exploring a complete agent workflow: routing a task, gathering structured notes, and reviewing the result against explicit quality checks.

| Agent | Role | Outcome |
| :--- | :--- | :--- |
| **Research Scout** | Turns a question into evidence notes | Traceable research handoff |
| **Task Router** | Sends a request to the right workflow | Predictable delegation |
| **Eval Guardian** | Checks drafts against quality criteria | Actionable review before delivery |

### What makes these AI engineering projects strong

Each project is designed to show more than a model call: a useful workflow, clear inputs and outputs, traceable decisions, evaluation criteria, and a safe path for a human to review the work.

## How I Think About Agent Systems

~~~mermaid
flowchart LR
    A[Request] --> B[Task Router]
    B --> C[Research Scout]
    C --> D[Eval Guardian]
    D --> E[Reviewed Response]
~~~

The goal is not just to make an agent work. It is to make its decisions understandable, its outputs easy to evaluate, and its workflow safe to improve.
